6. How to Deploy

The project has zero backend dependencies and deploys as static assets:
- GitHub Pages: Push repository $\to$ In Settings $\to$ Pages, set root to `/web`.
- Netlify: Drag-and-drop the `web/` folder into Netlify Drop, or connect repository with publish directory set to `web`.
- Vercel: Run `npx vercel` inside `web/` or link repository.
